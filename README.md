# 📊 Laziness Analysis — Power BI Dashboard

## 📌 Project Overview

This project is an **Employee Laziness Analysis Dashboard** developed using **Microsoft Power BI**.

The objective of this project is to analyze employee-related data and identify the major factors associated with employee laziness, productivity, workload, and workplace behavior.

The dashboard provides interactive visualizations that allow users to explore employee performance and understand the factors contributing to the **Laziness Index**.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze employee laziness and productivity patterns.
* Identify factors that influence the Laziness Index.
* Compare laziness across different employee categories.
* Analyze employee-related metrics using interactive Power BI visuals.
* Identify the major contributors to employee laziness using a **Decomposition Tree**.
* Provide parameter-based analysis for adjusting and understanding the results.
* Build an interactive and user-friendly business intelligence dashboard.

## 📊 Dashboard Features

### 1. Employee Analysis

The dashboard provides an overview of employees and their associated metrics.

Users can filter and analyze employee-related information interactively.

### 2. Laziness Index Analysis

The **Laziness Index** is used as a key analytical metric to understand differences in employee laziness.

The dashboard allows users to compare the index across different dimensions.

### 3. Decomposition Tree

A **Decomposition Tree** is included to investigate the factors contributing to the Laziness Index.

This allows users to start with the overall metric and drill down into different dimensions to understand **why a particular result occurs**.

### 4. Adjustment / Parameter Analysis

The project includes a parameter-based analysis that allows users to change an adjustment value and observe how the analysis changes dynamically.

This demonstrates the use of **Power BI What-If/parameter functionality and DAX logic**.

### 5. Interactive Filtering

The report uses Power BI's interactive capabilities, allowing users to:

* Filter employees
* Compare categories
* Explore different dimensions
* Analyze individual segments
* Interactively investigate the data
